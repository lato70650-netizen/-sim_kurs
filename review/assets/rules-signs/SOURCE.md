# Изображения дорожных знаков

Заменены 15 ноября 2026 года файлами из архива, переданного пользователем через ветку sign-assets-transfer, transfer/road-signs.zip. В архиве есть SVG, PNG и sources.json. Для сайта использованы исходные SVG без перерисовки или изменения геометрии. Нормализованы только окончания строк и концевые пробелы; хеши оригиналов и файлов сайта сохранены раздельно. Номера, размер файлов и SHA-256 записаны в sources.json.

Указанный источник — Wikimedia Commons, а не официальный портал опубликования ПДД. Ссылки перенесены из переданного манифеста; напрямую открыть страницы из этой среды пока не удалось. Изображения визуально проверены в браузере, но это не подтверждение актуальности всех нормативных формулировок курса.
