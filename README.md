# -sim_kurs
курс по сим для подростков

## Главная страница курса

Статический сайт: `index.html`, `style.css`, `script.js`, `auth.js`, `assets/`, `vendor/`. Сборка и установка зависимостей не нужны.

Локальный просмотр из корня репозитория:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Для публикации на GitHub Pages: Settings → Pages → Deploy from a branch → `main`, `/ (root)`. Публикация выполняется отдельно после отправки файлов в GitHub. Все ресурсы используют относительные пути.

Сейчас готовы главная страница и раскрывающиеся описания трёх блоков. Уроки, задания, итоговая игра и сохранение прогресса будут добавлены позже.

## Аккаунты

Кнопка «Войти» открывает вход и самостоятельную регистрацию по email и паролю. После регистрации при отключённом подтверждении email пользователь сразу входит в аккаунт. Supabase сохраняет и обновляет сессию; «Выйти» завершает текущую сессию. При регистрации интерфейс требует пароль от 8 символов.

Проект Supabase: `sim_kurs` (`vkdszexertrpywykviob`). В `auth.js` находится только публичный publishable key. Секретные и service-role ключи не используются. Email provider и регистрация должны быть включены, подтверждение email — выключено. Таблицы и сохранение прогресса эта функция не добавляет.

Клиент Supabase JS 2.119.0 сохранён локально в `vendor/`, чтобы вход не зависел от CDN. Лицензия находится рядом. При обновлении клиента сохранять точную версию и менять URL скрипта.

Проверено в Chromium 7 ноября 2026 года через настоящую форму: создание тестового аккаунта, сессия после обновления страницы, выход, ошибка неверного пароля, повторный вход и выход. Мобильная форма и закрытие по Escape также проверены.
