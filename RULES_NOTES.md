# Второй блок — локальная реализация

Подготовлено 14 ноября 2026 года после «да, делай». Публикация не выполнялась. Материал пользователя: «часть 2 описание.docx». Структура — пять уроков, по одному HTML на урок, с открытыми смысловыми разделами, фотографиями, возрастными блоками, карточками знаков и шестью шагами перехода.

Вход из второго блока index.html → rules.html → rules-lesson-1.html … rules-lesson-5.html. Обложка всегда начинает первый урок. Вопросы после каждого урока обязательны для первого прохождения, ошибку можно исправить. Всего 13 ситуаций из материала документа, ответы показаны после выбора. Отдельного итогового экзамена или третьего блока не добавлено.

Предложенные ранее варианты вопросов приняты как рабочие допущения после общего «да»: доступ сразу с главной без входа/без завершения первого блока; возрастные группы видны вместе; последовательные уроки с мини-заданиями. Регистрацию, первый блок, глобальные стили и анимации не меняли. В тесте первого блока только уточнили селектор его кнопки, поскольку кнопок стало две.

Прогресс rules.js: sim-rules-progress-v1, completed 0…5. Не связан с ключом знакомства. localStorage → sessionStorage → открытые уроки с пояснением при полном запрете хранилищ. Это не серверная синхронизация и не защита доступа. Завершение сохраняется явной кнопкой после заданий; уже пройденный урок можно перечитывать без повторной обязательной проверки.

## Перед публикацией

Знаки в assets/rules-signs — авторские учебные перерисовки, НЕ проверенные официальные изображения. Требуется сверка/замена по приложению 1 к ПДД, особенно пиктограммы 3.35, разделённые дорожки и переходы. Фотографии сгенерированы отдельно, их происхождение в assets/rules-scenes.SOURCE.md.

Текст документа не объявляется юридически проверенным. В нём возрастные группы названы «от 7 до 14» и «старше 14»: требуется устранить неоднозначность именно для 14-летних по актуальной редакции ПДД. Также подтвердить сопровождение ребёнка на велосипеде, условия выбора инфраструктуры, дневной свет и светофоры. До уточнения текст сохраняет присланные формулировки. Последние самостоятельные онлайн-проверки нормативных сайтов не удались, поисковый плагин недоступен. Внешние курсы не просмотрены. Не публиковать эту версию как нормативно проверенную.
