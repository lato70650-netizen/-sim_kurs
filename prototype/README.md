# Изолированный дизайн-прототип

Ветка: design/night-route-prototype. База: b91dd6a. Изменения только внутри prototype/. Рабочий сайт, уроки, авторизация, Supabase и прогресс не изменены. Прототип не опубликован.

## Просмотр

Из корня этой рабочей копии:

    python3 -m http.server 8123 --bind 0.0.0.0

Адрес в облачной среде: http://127.0.0.1:8123/prototype/

Этот localhost относится к облачной среде. Для своего компьютера используйте автономный HTML-экспорт или скачайте ветку и запустите тот же сервер локально. Прототип использует обычные HTML/CSS/JavaScript, дополнительных библиотек или сборки нет. Относительные ссылки на исходные страницы работают при обслуживании корня репозитория.

## Содержание

- Главная с тремя модулями. Первые два открывают исходные introduction.html и rules.html. Третий показывает честный статус подготовки игры и существующую программу; новая итоговая игра не имитируется.
- Фотореалистичный подросток и вечерний город, тёмно-синий фон, лайм и голубой.
- Карточки с объёмом, короткой реакцией на наведение и доступным раскрытием программы. На телефоне действия доступны нажатием, hover не требуется.
- Пример «Какие бывают СИМ»: пять переключаемых устройств. Все абзацы берутся дословно из разделов lesson-2.html. Полный текст доступен через native details; без JS остаётся рабочее раскрытие электросамоката.
- Дополнительные раскрытия в действующих уроках не вводились: это только изолированный пример согласно новому заданию.
- Ничего не записывает в хранилище, не обращается к Supabase, не загружает auth.js, не заявляет сроки или синхронизацию.

## Проверка

    node prototype/tests/prototype.spec.cjs

Проверяет хеши всех исходных файлов базы, три модуля, точность текстов пяти устройств, раскрытие мышью/клавиатурой, переходы к существующим страницам, режим без JS, мобильное переполнение, отсутствие ошибок/404 и обращений к Supabase/хранилищу.

## Дальнейшее внедрение

После согласования выбрать, какие части дизайна переносить. Вначале — только согласованную главную, затем отдельно один урок. При переносе сохранить принятые переходы, оригинальные SVG знаков, тексты и ключи локального прогресса. Проверять существующие tests/introduction.spec.cjs и tests/rules.spec.cjs. Не подключать декоративную карточку вместо реального задания. Перенос на остальные страницы и публикация требуют отдельного согласования.
