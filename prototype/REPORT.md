# Отчёт об изолированном дизайн-прототипе

## Статус

Подготовлен для согласования в ветке `design/night-route-prototype`, база `b91dd6a`. Изменения ограничены папкой `prototype/`. Публикация, перенос на main и изменение действующего сайта не выполнялись. После согласования требуется отдельное решение о внедрении.

## Результат

- Главный экран с вечерней фотореалистичной обложкой, тёмно-синими поверхностями, лаймовыми и голубыми акцентами.
- Ровно три карточки модулей в прежней последовательности. Реальные переходы к знакомству и правилам. У третьего модуля статус подготовки игры; недостающие задания не придуманы.
- Пример карточки первого модуля: пять устройств, выбор, раскрытие полного описания и ссылка на существующий урок.
- Компьютерная и мобильная раскладки, клавиатурный фокус, native details, reduced-motion и полезный режим без JavaScript.

Объём карточек выполнен средствами CSS. Фотографии транспорта переиспользованы из курса; новые объёмные 3D-рендеры устройств не создавались. Новая фотография обложки подготовлена отдельно по пользовательскому образцу; вымышленный синий знак с самокатом в неё не перенесён.

## Файлы

Новые файлы реализации: `prototype/index.html`, `style.css`, `app.js`, `device-data.js`, `assets/night-hero.png`. Тест и контрольная опора: `tests/prototype.spec.cjs`, `baseline-sha256.json`. Задание, просмотр, источники и описание системы: `BRIEF.md`, `README.md`, `assets/SOURCE.md`, `assets/night-hero.prompt.txt`, `DESIGN.md`, `.impeccable/design.json`, настоящий `REPORT.md` — все внутри `prototype/`.

Корневые HTML/CSS/JavaScript, уроки, вопросы, ответы, объяснения, изображения знаков, авторизация и исходные иллюстрации не изменены. Новых библиотек, платных сервисов или сборки нет.

## Сохранность учебных материалов

Проверка SHA-256 по `baseline-sha256.json` подтверждает неизменность всех 67 исходных отслеживаемых файлов. Независимый просмотр также подтвердил совпадение 14 абзацев пяти устройств с `lesson-2.html`. Заголовки уроков и формулировки заданий не менялись. В первом модуле остаются все пять существующих уроков, включая возраст и права. Во втором сохранены пять уроков, медицинское дополнение и имеющиеся задания.

Прототип не загружает auth.js, не обращается к Supabase и не записывает localStorage/sessionStorage. Он не добавляет продолжительность курса, баллы, фиктивный прогресс или обещание синхронизации.

## Проверка

Выполнен `node prototype/tests/prototype.spec.cjs` при локальном сервере на порту 8123. Пройдены ширины 1440 и 390px: три модуля, пять точных описаний, раскрытие мышью/клавиатурой, реальные маршруты, отсутствие горизонтального переполнения, ошибок JavaScript и 404. Отдельно проверены отсутствие запросов к Supabase/записи в хранилище и native-раскрытие без JS.

Независимый reviewer: «Блокеров нет» по brief, снимкам и коду. Замеченный пропуск пробела после скрываемого мобильного br исправлен. Финальный повтор tests/prototype.spec.cjs после исправления также пройден на 1440/390px и без JS; все 67 исходных файлов совпадают с базой. Эта оценка относится к прототипу, не к юридической точности курса.

## Просмотр и ограничения

Из корня рабочей копии: `python3 -m http.server 8123 --bind 0.0.0.0`, затем `http://127.0.0.1:8123/prototype/` в той же среде. Для браузера пользователя создан автономный HTML-экспорт `/workspace/shared/night-design-preview/sim-night-prototype.html` (около 11.9MB): изображения, шрифт, CSS и JavaScript встроены, ссылки на исходный курс абсолютные. Экспорт проверен через локальный HTTP8124: три модуля, переключение устройства, рабочее details, нет внешних запросов и ошибок JS. Localhost облачной среды не является публичной ссылкой.

Снимки: `/workspace/shared/night-prototype-1440.png`, `night-prototype-390.png`, `night-prototype-open-1440.png`, `night-prototype-open-390.png`; первый экран `/workspace/shared/night-design-preview/hero-desktop.png`. Удалённая main подтверждена на `b91dd6a`, без изменений.

Нормативная сверка ПДД в эту дизайн-задачу не входит и не объявляется завершённой. Точные изображения знаков сохранены в исходном курсе. Третий модуль пока не реализован.

## Следующий шаг

Получить выбор пользователя по прототипу. После одобрения отдельно перенести согласованную главную, затем проверить один согласованный урок. При каждом переносе сравнить исходные тексты, сохранить действующие кнопки/порядок и выполнить существующие проверки знакомства и правил. Автоматически распространять дизайн на остальные страницы нельзя.

## Последующее разрешение на публикацию
После сдачи прототипа пользователь назвал мятный дизайн вариантом А, новый — вариантом В, и явно разрешил публикацию В для просмотра. Опубликована только новая главная; А доступен отдельно. Уроки остаются прежними. В публикационную главную возвращена исходная рабочая форма входа без изменения SDK/логики. Дальнейший статус и адреса — ../VARIANTS.md.
