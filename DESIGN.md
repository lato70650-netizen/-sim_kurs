# Визуальная система

Яркая фотографическая городская тема; тёплый светлый фон, выразительная типографика, насыщенный бирюзовый основной цвет, оранжевая кнопка, лаймовый, бирюзовый и абрикосовый блоки, жёлтая секция формата обучения. Главная работает в режиме Read: понять состав курса и выбрать блок.

Токены: фон #fffdf6; основной текст #123c39; основной цвет #087b70; акцент #ff703c; вторичный текст #405e58; разделители #c8dacf. Радиус крупных поверхностей 16px, кнопок 9px. Основной шрифт Arial/Helvetica с системным запасным sans-serif, без внешних сетевых зависимостей.

На широком экране заголовок и фотореалистичное изображение стоят рядом; ниже три последовательных блока разного фонового тона. На телефоне всё складывается в одну колонку. Нумерация означает порядок обучения. Описания блоков раскрываются настоящими кнопками с aria-expanded и aria-controls. Все фотоизображения созданы ИИ; источник указан в подвале и assets/PHOTO_SOURCE.md. Текст и функции доступны без анимации; reduced-motion отключает плавную прокрутку. Все пути относительные для GitHub Pages в подпапке репозитория.
