# Визуальная система — городской журнал

Утверждённое направление: стильно и чуть по-взрослому для подростков 12–13 лет; больше энергии; фото с графикой, указателями и наклейками. Главная в режиме Read: понять курс и выбрать один из трёх последовательных блоков.

Токены: paper #f8f5ec; ink #183b35; primary #087467; orange #ff713d; muted #4a6058; line #bdc8ba; lime #d4ef77; yellow #ffe263. Локально размещённый variable-шрифт Onest, 100–900, с кириллицей, лицензия OFL в assets/Onest-LICENSE.txt. Крупные заголовки 72px максимум на обложке, 49px в программе; мобильные размеры адаптивные. Контролы 5px radius, поясняющая секция 12px.

Обложка: крупный заголовок с оранжевым подчёркиванием, ровное фото 3:2, повёрнутая жёлтая наклейка «Сначала подумай». Фото не наклонять: явное пожелание пользователя. Все фото сохраняют исходные пропорции 3:2. Обложку и программу связывает лаймовая полоса «Замечай → Выбирай → Действуй». Три блока имеют журнальную композицию: линейка, номер этапа, снимок с цветной подписью, описание и раскрытие программы. Без фоновых карточек.

Signature interaction: при наведении наклейка выпрямляется и слегка поднимается; фотография усиливает насыщенность. Реакция только на устройствах с hover, без постоянного движения. Reduced-motion отключает переходы и smooth scroll. Клавиатура: видимый фокус, skip-link, доступные кнопки aria-expanded/aria-controls. На телефоне одна колонка. Уроки и игра пока обозначены как будущие; не имитировать прогресс.

Фотоизображения созданы ИИ, раскрытие в подвале; источник assets/PHOTO_SOURCE.md. Относительные пути для GitHub Pages. Пользователь разрешил публикацию выбранной мятной версии с самокатчиком на GitHub Pages.

## Уточнение после просмотра
Убрать наклейки с фото: пользователь считает их невыразительными и упрощающими дизайн. Снимки чистые, без надписей поверх. Вернуть насыщенные лаймовый, бирюзовый и абрикосовый фоны трём блокам; журнальный характер сохранять через Onest, иерархию и нумерацию. Скругления 14px. Декоративные наклейки не возвращать.

## Самокатчик внизу
Перед подвалом спокойная линейная SVG-сцена: маленький силуэт в шлеме с оранжевой курткой проезжает по тонкой линии к финишу. IntersectionObserver запускает один шестисекундный проезд при 60% видимости сцены. Автоматического повторения нет. Нажатие на самокатчика повторяет поездку; кнопка имеет доступное название и фокус. При prefers-reduced-motion сцена неподвижна у финиша, включая смену настройки во время движения. Анимация только transform, расстояние адаптируется к ширине через cqw.
