Реализованные ресурсы: `module-one-v2.css` (палитра, типографика, формы, адаптивность), `course-depth.css` (общие три уровня теней и небольшой краевой свет), `module-one-v2.js` (только отображение существующего прогресса), локальный Manrope и изображения в `assets/module-one-v2/`. На семи учебных страницах сохраняются прежние скрипты `introduction.js` и `introduction-data.js`; `components-module-one.html` — отдельная демонстрация компонентов. Новый слой подключён после прежних CSS. Общий CSS глубины пока применяется только в этой области; перенос на остальные страницы предстоит по мере миграции. Главная В, архив А, правила, авторизация и Supabase вне текущей области.

Пользователь уточнил объём до всего знакомства и выбрал раскрытие описания под изображением. Последнее дополнение по референсу уже учтено: мягкие тени и краевой свет, часы с приблизительным временем чтения, информационная полоса реальных свойств курса, локальный прогресс, линейный знак самоката, отсутствие декоративных точек. Электроскейтборд урока 4 стоит рядом с существующим сравнением обычного и электрического скейтборда. Последовательность и 42 исходных учебных абзаца сохраняются; исходные учебные JS и данные не меняются.

Для продолжения сначала читать CONTRACT.md и scoped DESIGN.md, затем актуальные [NEXT.md](NEXT.md) и [REVIEW.md](REVIEW.md): там записаны состояние работы, проверки и итог независимого ревью. Само по себе полное ТЗ не разрешает немедленно перенести все три модуля или опубликовать черновик. Следующий шаг — предоставить готовый первый блок для визуального согласования; последующие этапы следуют согласованному объёму.

Проверки сохранности и браузера находятся в `tests/`; результаты текущей проверки записаны в [REVIEW.md](REVIEW.md). Эта документация извлечена из исходников и не означает новый запуск проверок. Impeccable launcher/detector недоступны в среде; не заявлять их запуск. Для локального просмотра вход — `introduction.html`, инвентарь — `components-module-one.html`. `export-preview.py` собирает автономный файл просмотра; экспорт не является публикацией сайта.
