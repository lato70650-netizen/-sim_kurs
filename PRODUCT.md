# СИМ — двигайся с умом

Небольшой открытый курс для подростков 12–13 лет. Размещение — GitHub Pages, без серверной части и регистрации на текущем этапе. Основная программа — COURSE_STRUCTURE.md.

Текущий объём: главная страница и представление трёх блоков. Уроки, задания, игра и сохранение прогресса пока не реализованы. Не показывать вымышленные результаты или работающие уроки.

Три блока: знакомство с разными СИМ; правила от подготовки до завершения поездки; итоговый виртуальный маршрут. Объяснения должны быть короткими, наглядными и понятными, без излишне детского оформления. Пример автошкольного кабинета используется только как ориентир для последовательности и будущего прогресса.

Согласованный новый стиль: городской журнал, больше энергии и движения, фото с графикой и указателями, без наклеек на фотографиях. Верхнее фото строго ровное. Пользователь разрешил загрузить выбранную мятную версию с самокатчиком на GitHub Pages.

Редакционное правило пользователя: никогда не ставить точки в конце заголовков.
