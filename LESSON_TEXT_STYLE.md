# Оформление текстов курса по СИМ

Принято 20 ноября 2026 года. Цель: ученик читает материал по частям, а не длинным сплошным полотном.

## Как готовить тексты

- Сохранять авторские формулировки, определения ПДД, порядок уроков, вопросов и объяснений. Редактирование содержания — отдельная согласованная работа.
- Один смысловой фрагмент — один абзац. Не объединять разные правила, примеры и исключения в одну длинную строку.
- Для самостоятельных частей использовать заголовки второго и третьего уровня. Не выдумывать подзаголовки, которые меняют логику урока.
- Перечни оформлять списками, а порядок обязательных действий — нумерацией.
- Выделять жирным только важные термины или ключевой вывод; не делать жирным весь абзац.
- Важное предупреждение оформлять уже существующим компонентом информационного блока. Не создавать новую карточку ради каждого предложения.
- Сложные тексты сопровождать ранее согласованными схемами и карточками, но не скрывать обязательные объяснения за дополнительными кликами.
- После любой правки сравнить текст с утверждённым оригиналом дословно; проверить мобильный вид, контраст и доступность.

## Markdown как черновой формат

В рабочих файлах Markdown можно писать так:

```markdown
## Название раздела

Короткий вводный абзац.

### Что важно проверить

- Первый пункт.
- Второй пункт.

**Важно:** текст подтверждённого правила.
```

Markdown нужен для *подготовки* текстов, но не является новым сервисом и не должен выводиться на сайте как сырые символы `##` или `**`. Сайт курса сейчас использует статические HTML-уроки: при переносе в сайт заголовки, списки и выделения должны стать соответствующими HTML-элементами. Не подключать внешние рендереры или библиотеки, если нет подтверждённой необходимости.
